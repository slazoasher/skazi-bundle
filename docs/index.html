Frequently asked questions

Windows says “Windows protected your PC”

The installer isn’t code-signed yet. Choose More info → Run anyway to continue.

Where do I find the plugins in my DAW?

Look for SKAZI in your plugin browser. In Cubase, use Studio → VST Plug-in Manager → Rescan.

Do my old projects still load?

Yes. Existing plugin IDs remain compatible between versions.

How do I uninstall?

Windows: Settings → Apps → SKAZI Bundle. Mac: open Applications → SKAZI and run Uninstall SKAZI Bundle.
