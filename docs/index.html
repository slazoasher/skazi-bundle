FAQ

Windows says "Windows protected your PC"

The installer isn't code-signed yet, so SmartScreen doesn't know it. Click More info → Run anyway. It's safe.

Where do I find the plugins in my DAW?

Under the vendor SKAZI. In Cubase, if they don't show, use Studio → VST Plug-in Manager → Rescan.

Do my old projects still load?

Yes. The plugin IDs stay the same between versions, so sessions keep loading them.

How do I uninstall?

Windows: Settings → Apps → SKAZI Bundle. Mac: run Uninstall SKAZI Bundle in Applications → SKAZI.
